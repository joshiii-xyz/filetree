## [0.1.0] - 2026-08-14

### Added

- Recursive, deterministic directory tree output with file and directory counts.
- Depth limits, hidden-name control, shell-style exclusions, ASCII mode, and JSON output.
- Safe non-recursive symlink handling and readable filesystem error reporting.
